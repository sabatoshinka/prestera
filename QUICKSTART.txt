PIBBLE CLUB — 0.2.0 beta
Windows 10/11, 64-разрядная версия

ЗАПУСК
1. Распакуй всю папку из архива.
2. Открой Pibble Club.exe. Node.js устанавливать не нужно.
3. Нажми «Создать комнату», введи имя и скопируй приглашение.
4. Друг запускает такую же копию приложения, нажимает «К друзьям»
   и вставляет приглашение.

В одной локальной или общей VPN-сети отдельный сервер не нужен.
Для интернета у создателя должен быть доступный внешний адрес:
укажи его при создании комнаты и перенаправь TCP и UDP порт 45454
на свой компьютер. Порт можно изменить.
Разреши приложению доступ к нужной сети в брандмауэре Windows.
Прямое соединение не работает через некоторые виды NAT и запреты UDP.
Для такой сети используй общую VPN-сеть (например, уже настроенную
Radmin VPN). Обязательных сторонних сервисов в приложении нет.

ВОЗМОЖНОСТИ
- До 8 участников, прямые голос, видео и передача файлов.
- Шумоподавление и эхоподавление микрофона.
- Камера, демонстрация окна или экрана до 1080p / 60 FPS.
- Звук только выбранного приложения — отдельный режим по умолчанию
  для окна. Весь звук компьютера передаётся только при явном выборе.
- Картинки и GIF: перетащи в чат, вставь из буфера или нажми скрепку.
- Файлы до 25 МБ. Звуки звуковой панели до 30 секунд / 10 МБ.
- Треугольник на звуке — прослушать у себя; карточка — сыграть в комнате.

ГОРЯЧИЕ КЛАВИШИ (МОЖНО ИЗМЕНИТЬ)
Ctrl + Shift + M — микрофон
Ctrl + Shift + D — выключить / включить весь звук и микрофон
Ctrl + Shift + V — камера
Ctrl + Shift + S — демонстрация
Ctrl + Alt + 1 / 2 / 3 — первые три звука

ЗАЩИТА
При подключении: Diffie–Hellman X25519 и ChaCha20-Poly1305 через TLS.
Для каждого подключения создаются новые сеансовые ключи.
Голос, камера, демонстрация, чат и файлы шифруются WebRTC.
Без секретного приглашения войти нельзя через штатный протокол:
знания одного IP и открытого порта недостаточно.
Любой, у кого есть приглашение, может войти: отправляй его лично.
Если ссылка утекла, закрой комнату и создай новую.
IP-адреса не скрываются; шифрование не защищает от перегрузки сети.

У всех должна быть версия 0.2.0: с 0.1.0 соединение несовместимо.
Для переноса своих данных закрой приложение и скопируй PibbleData
из старой папки в новую. Друзьям отправляй чистый архив без PibbleData.

Если создатель выходит, комната закрывается для всех.
История и звуки хранятся локально в папке PibbleData рядом с программой.
Локальная история дополнительно не зашифрована.
Доставка сообщений отсутствующим участникам не выполняется.

1080p / 60 FPS — целевой режим, а не обещание при любой нагрузке.
На каждого зрителя нужен отдельный исходящий поток (до 10 Мбит/с
в режиме 1080p60). Несколько демонстраций увеличивают нагрузку.
Нативный захват звука проверен на Windows 10 22H2, сборка 19045.
Некоторые старые сборки и защищённые приложения могут не поддерживаться.

Подробности — в README.md, описание защиты — в SECURITY.md.
