PRESTERA 0.7.0 — Windows 10/11 x64

Распакуй весь архив и запусти Prestera.exe. Для этой версии обновитесь оба.

ПЛЕЙЛИСТЫ
Кнопка «Музыка» → «Для комнаты» → название → «Создать плейлист».
Добавь аудиофайлы, выбери плейлист и нажми «В очередь», затем воспроизведение.
Плейлисты сохраняются в %APPDATA%\Prestera\Profile\playlists.json.
В конфиге хранятся пути: исходные аудиофайлы не копируются. Если переместишь
или удалишь файл, добавь его заново. В комнате передаётся аудиопоток.
Онлайн-плейлисты VK/Spotify/SoundCloud/YouTube пока не реализованы.

УЧАСТНИКИ
ЛКМ по участнику — компактная карточка возле аватара.
«Открыть профиль» — большой профиль; свой профиль можно редактировать.
ПКМ по участнику — отдельная громкость голоса, музыки и демонстрации.
Эти уровни действуют только у тебя, в текущем сеансе комнаты.

ПОДКЛЮЧЕНИЕ ЧЕРЕЗ VPS
Сначала разверни сервер из отдельного комплекта Prestera-Server с GitHub.
Инструкция — server/DEPLOY.md, включена также в этот архив.
«Создать комнату» → «Через VPS · без VPN», адрес сервера и ключ создания.
Друзьям отправь полное приглашение. Radmin для этого режима не нужен.
Если прямой путь недоступен, приложение использует TURN на VPS.
«Только через ретранслятор» помогает проверить TURN; по умолчанию выключено.
Комната существует, пока создатель в ней; предельная длительность — 23 часа.
В этом комплекте TURN использует UDP/TCP 3478. Он не гарантирует работу
в сетях, блокирующих и эти порты, и прямое соединение.

ПОДКЛЮЧЕНИЕ НАПРЯМУЮ
Осталось доступно по адресу в локальной/VPN-сети или с доступным внешним IP.
Для интернета без VPS понадобятся доступность TCP/UDP-порта создателя и
возможность прямой передачи между участниками.

ОБНОВЛЕНИЯ И ДАННЫЕ
Настройки → Обновления → Проверить обновления → Скачать обновление.
После загрузки выйди из комнаты и нажми «Перезапустить и обновить».
При запуске приложение проверяет GitHub; эту проверку можно отключить.
Обновление проверяется по SHA-256 и распаковывается отдельно от старой версии.
Данные теперь общие для всех новых сборок: %APPDATA%\Prestera\Profile.
Открыть эту папку можно в настройках обновлений. Не публикуй её:
в ней находятся история, настройки и ключ создания комнат на твоём VPS.

ПЕРВЫЙ ПЕРЕХОД СО СТАРОЙ ВЕРСИИ
Закрой старую версию и распакуй новую рядом со старой папкой сборки.
При первом запуске перенесётся последний использованный соседний профиль.
Если папки находятся в разных местах, до первого запуска скопируй старую
PibbleData рядом с новым Prestera.exe. Оригинал при переносе не удаляется.
После этого обновления используют общую папку данных без ручного копирования.
В версиях до 0.7.0 встроенного обновления нет: первый переход делается вручную.

ДЕМОНСТРАЦИЯ
При запуске демонстрации можно выбрать лимит от 1 до 50 Мбит/с на зрителя.
«Автоматически по выбранному качеству» использует 3–10 Мбит/с.
Настройки → Голос и видео позволяют изменить лимит уже запущенного стрима.
Сохрани настройки, чтобы применить его. 1080p60 зависит от приложения, ПК и сети.
При потерях поток может временно снижаться. Более высокий лимит не резервирует
скорость сети; каждому зрителю отправляется отдельный поток.
Для захвата доступны режимы «Без рамки» и «Совместимый».

Подробности проверок сборки — VALIDATION.md в папке релиза.
